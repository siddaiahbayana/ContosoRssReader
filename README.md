ContosoRssReader
Overview
ContosoRssReader is a lightweight, modern RSS subscription management application designed to handle subscription lists efficiently with an intuitive workflow. Built as part of a development and architecture lab, this project emphasizes clean separation of concerns, robust tooling, and rapid implementation using .NET and modern CLI workflows.
Key Features & MVP Boundary
• Subscription Management: Easily add, list, and manage RSS feed subscriptions.
• In-Memory Storage: Initial Minimum Viable Product (MVP) utilizes fast, in-memory data structures for seamless subscription tracking without the overhead of external databases or local DB dependencies.
• Streamlined Extensibility: Designed with architectural extensibility in mind to allow future integration of full RSS parsing engines and persistent data layers.
Technology Stack & Prerequisites
• Language/Runtime: Python 3.12 (for tooling/management scripts) & .NET 10 SDK.
• Development Tools: • VS Code with the C# Dev Kit extension. • specify-cli for project initialization and workflow management. • GitHub Copilot for AI-assisted development and architectural summarization.
